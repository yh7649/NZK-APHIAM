# Annual Plant Generation and Emissions Dataset

Status: archived. The monthly KEPCO thermal panel is the preferred dataset for
near-term analysis. This annual plant panel is retained for reference and is
not the active analysis path.

This is the version-controlled documentation for the generated annual plant
dataset in `data/archive/annual_plant/`. The `data/` directory is
ignored by git, so the README stored beside the CSVs is useful locally but this
file is the copy intended to be committed.

The main analysis file is:

- `data/archive/annual_plant/annual_plant_generation_emissions.csv`

Related audit and validation files in the same generated folder explain how
the panel was constructed and where records need review.

## Main Dataset

`annual_plant_generation_emissions.csv` has `{final_rows}` plant-year rows
covering `{annual_start_year}`-`{annual_end_year}` after the workflow is run.
Each row is one canonical EPSIS plant-year where generation and/or emissions
evidence is available.

Coverage variables are defined by the generated outputs after a team member
runs the scripts:

- `{final_rows}`: rows in `annual_plant_generation_emissions.csv`
- `{generation_rows}`: selected generation rows from EPSIS
- `{emissions_comparison_rows}`: plant-year-pollutant comparisons
- `{final_review_rows}`: final rows flagged for review
- `{operator_category_counts}`: count by `operator_category`

The annual panel is plant-level. It should not be interpreted as unit-level
even when the plant name contains a unit-like label such as `#1`; those labels
come from EPSIS canonical plant grouping and can represent a grouped plant
fleet, a combined-cycle block, or a named plant asset.

## Related KEPCO Monthly Panel

The more spatially detailed KEPCO subsidiary dataset is:

- `data/kepco/processed/kepco_monthly_generation_emissions.csv`

That file has `{monthly_rows}` monthly rows covering `{monthly_start_date}`
through `{monthly_end_date}` after the workflow is run. It is closer to unit
resolution than the annual panel because it preserves `plant_name`,
`plant_number`, and `original_korean_unit_name`.

Resolution variables in the monthly panel:

- `{plant_site_identities}`
- `{unit_reporting_identities}`
- `{numeric_unit_identities}`

`unit/reporting identities` is the broadest finest-source identity count. It
uses:

```text
source_dataset + plant_name + plant_number + original_korean_unit_name
```

This preserves cases where the source reports something finer or messier than a
clean numeric unit, for example:

- `Samcheonpo`, `3.0`, `3A호기; 3B호기`
- `Gunsan`, blank `plant_number`, `복합 CC`
- `Jeju`, blank `plant_number`, `제주복합1호기`

`numeric unit identities` only counts rows where `plant_number` is populated,
using:

```text
source_dataset + plant_name + plant_number
```

In plain terms, `numeric unit identities` are clean numbered units.
`unit/reporting identities` are the finest spatial/reporting units preserved
from the source, even when they are not clean numeric units.

## Fuel Detail

The analysis preserves fuel/source labels as finely as the sources allow. It
does not force rows into a reduced technology taxonomy. This is deliberate:
labels such as `경유`, `중유`, `유류`, `B-C`, `LSWR`, `LPG`, bio-heavy-oil,
mixed oil/gas, coal variants, gas/LNG, hydro, pumped hydro, nuclear, and CHP
source labels carry information that would be lost if every row were forced
into a short model category list.

Annual fuel counts should be computed from the generated panel:

- `{annual_fuel_counts}`

The R analysis groups emission factors by detailed `fuel`/`energy_type`
categories. Pollution-control timing should be estimated empirically, for
example using break tests on emission-factor time series, rather than assumed
from static fuel labels.

## Fuel Validation

Fuel classifications are externally checked in:

- `data/archive/annual_plant/annual_fuel_validation.csv`

The validation compares the final panel fuel label against the KPX EPSIS annual
generator roster, which is separate from the EPSIS annual generation extract
used as the generation denominator.

Fuel validation statuses are generated by the workflow:

- `{fuel_validation_status_counts}`

Known equivalent labels are normalized before comparison. Examples include:

- `가스` and `LNG` -> natural gas
- `석탄`, `역청탄`, and `유연탄` -> coal
- `수력` and `일반수력` -> hydro
- `농축U`, `천연U`, and `원자력` -> nuclear

Remaining `mismatch` rows should be treated as a review queue, not silently
recoded.

## Output Files

- `annual_plant_generation_emissions.csv`: final annual plant-year panel.
- `epsis_annual_plant_generation.csv`: selected EPSIS generation rows after
  plant assignment and row classification.
- `epsis_generation_row_audit.csv`: audit table for every EPSIS annual
  generation row, including row class, assignment method, confidence, and
  exclusion reason.
- `epsis_generation_review.csv`: unresolved or low-confidence EPSIS generation
  rows requiring review.
- `annual_emissions_candidates.csv`: all standardized annual emissions
  candidates from direct subsidiary data, CleanSYS, and ENV-INFO.
- `annual_emissions_comparison.csv`: source-by-source pollutant comparisons and
  selected source per plant-year-pollutant.
- `annual_fuel_validation.csv`: final fuel label checked against the external
  EPSIS annual generator roster.
- `metadata.json`: checksums, validation counts, coverage summaries, and build
  settings.

## Main Columns

- `year`: calendar year.
- `plant_id`: stable canonical EPSIS plant identifier.
- `plant`: canonical plant name.
- `company`: EPSIS operator or company name.
- `operator_category`: `kepco` or `private_or_other`.
- `fuel`: selected EPSIS fuel label for the plant-year.
- `generation_mwh`: annual gross generation in MWh.
- `nox_kg`, `sox_kg`, `tsp_kg`: selected annual pollutant mass in kilograms.
- `nox_kg_per_mwh`, `sox_kg_per_mwh`, `tsp_kg_per_mwh`: annual emission
  factors using gross generation.
- `generation_source`: generation source, usually KPX EPSIS annual generation.
- `nox_source`, `sox_source`, `tsp_source`: selected emissions source for each
  pollutant.
- `generation_confidence`: confidence of the EPSIS generation assignment.
- `emissions_confidence`: confidence or review status for selected emissions.
- `review_required`: `True` when the row has assignment, validation, source, or
  outlier concerns.
- `validation_flags`: semicolon-separated validation flags.

## Source Logic

Generation comes from KPX EPSIS annual generation. The pipeline classifies each
source row as a unit, plant total, fuel total, company total, regional total,
aggregate, or unresolved row. Explicit plant totals are preferred; otherwise
valid units are summed.

Emissions candidates come from three lanes:

- direct KEPCO subsidiary monthly data, aggregated to annual plant level;
- CleanSYS annual emissions;
- ENV-INFO annual emissions.

The selected emissions source uses the documented precedence:

1. direct subsidiary plant-level mass;
2. unique, confidently matched CleanSYS facility;
3. unique, confidently matched ENV-INFO individual site.

Sources are alternatives and are not added together.

## Regeneration

From the project root, regenerate the annual outputs with:

```bash
python -m nzk_aphiam.data.process.annual_panel
```

Regenerate the related monthly KEPCO subsidiary panel with:

```bash
python -m nzk_aphiam.data.process.thermal
```

After regeneration, use `metadata.json` and the generated CSVs to fill the
variables above. The values are intentionally not hard-coded here because the
source websites can be revised and new years or facilities can be added.

For a quick local summary:

```bash
python - <<'PY'
import csv
import json
from collections import Counter

with open("data/archive/annual_plant/metadata.json", encoding="utf-8") as f:
    metadata = json.load(f)
print(metadata["counts"])
print(metadata["coverage"].get("fuel_validation_by_status", {}))

with open(
    "data/archive/annual_plant/annual_plant_generation_emissions.csv",
    newline="",
    encoding="utf-8-sig",
) as f:
    annual = list(csv.DictReader(f))
print(Counter(row["fuel"] or "UNKNOWN" for row in annual))

with open(
    "data/kepco/processed/kepco_monthly_generation_emissions.csv",
    newline="",
    encoding="utf-8-sig",
) as f:
    monthly = list(csv.DictReader(f))
print("monthly_rows", len(monthly))
print(
    "plant_site_identities",
    len({(r["source_dataset"], r["plant_name"], r["original_korean_plant_name"]) for r in monthly}),
)
print(
    "unit_reporting_identities",
    len(
        {
            (r["source_dataset"], r["plant_name"], r["plant_number"], r["original_korean_unit_name"])
            for r in monthly
        }
    ),
)
print(
    "numeric_unit_identities",
    len({(r["source_dataset"], r["plant_name"], r["plant_number"]) for r in monthly if r["plant_number"]}),
)
PY
```
