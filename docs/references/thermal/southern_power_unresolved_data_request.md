# Southern Power unresolved reporting-boundary request

Request the following from Korea Southern Power's public-data team before any
finer emissions allocation is attempted:

1. A definition of emissions unit codes, especially Namjeju Combined `1`,
   `11`, `2`, and `21`.
2. A dated crosswalk from each emissions unit/stack to physical gas turbines,
   heat-recovery steam generators, steam turbines, and combined-cycle blocks.
3. Confirmation of whether monthly pollutant mass is stack-, boiler-, block-,
   or plant-total mass.
4. Restored generation records for April 2017, September 2020, Namjeju Combined
   (June 2020 and October 2020–September 2023), and Shinsejong
   (August 2024–December 2025).
5. Confirmation that a missing daily generation row represents zero generation
   rather than missing reporting.

Until these questions are answered, plant/block emissions must not be allocated
to component turbines using generation shares.
